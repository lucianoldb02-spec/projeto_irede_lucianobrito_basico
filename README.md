Projeto: Expositor de Carros (Basico)
Autor: Luciano Damião de Brito
Trilha: 1
Versão utilizada no unity : 6000.3.13f1

Fiz esse projeto baseado nas minhas aulas Metaverso

O projeto possui
- 3 expositores de carros de luxo
- 3 plantas decorativas
- 1 mesas de escritório com suas respectivas cadeiras
- 1 conjunto de sofá para descanso
- 3 chaves na frente dos carros com grab interaction
- paredes
- Floor
- Céu

O Objetivo foi mostrar a confecção de um expositor de carros usando a tecnologia de Realidade Virtual, com a interação grab para pegar as chaves no expositor

Dificuldade em utilizar o simulador do unity
